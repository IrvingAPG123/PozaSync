# Frontend de PozaSync

El frontend de PozaSync utiliza React Native, Expo y TypeScript.
La navegación entre pantallas se organiza mediante Expo Router.

## Interfaces de la aplicación

| Pantalla | Función |
|---|---|
| Inicio de sesión | Acceso a la plataforma. |
| Registro | Creación de cuentas de clientes y técnicos. |
| Verificación de correo | Confirmación de la cuenta. |
| Panel del cliente | Administración de solicitudes. |
| Panel del técnico | Consulta de trabajos disponibles. |
| Perfil profesional | Gestión de información y especialidades. |
| Conversaciones | Consulta de mensajes pendientes. |
| Chat | Comunicación entre clientes y técnicos. |
| Perfil público | Consulta de información y valoraciones del técnico. |

## Plataforma objetivo

La aplicación está orientada a dispositivos Android.
Expo Web se utiliza como entorno auxiliar de desarrollo y pruebas.
