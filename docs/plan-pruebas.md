# Plan de pruebas funcionales de PozaSync

El objetivo es verificar el funcionamiento de la aplicación
y su compatibilidad con dispositivos Android.

## Pruebas pendientes de validación

- [ ] Registro de usuarios.
- [ ] Verificación de correo electrónico.
- [ ] Inicio de sesión según el rol.
- [ ] Creación y actualización del perfil profesional.
- [ ] Publicación de solicitudes de servicio.
- [ ] Carga y visualización de fotografías.
- [ ] Consulta y filtrado de solicitudes.
- [ ] Envío y recepción de mensajes.
- [ ] Gestión de acuerdos de servicio.
- [ ] Registro de calificaciones y reseñas.
- [ ] Validación de datos incorrectos.
- [ ] Control de acceso a funciones protegidas.
- [ ] Persistencia de la información.
- [ ] Ejecución y navegación en Android.

Los resultados deberán registrarse durante la etapa de evaluación.
