# Estructura del backend de PozaSync

El backend está desarrollado en Python mediante FastAPI.

## Directorios principales

- src/models: modelos de datos del sistema.
- src/routes: rutas y endpoints de la API.
- src/services: servicios internos de la aplicación.

## Archivos principales

- src/main.py: punto de entrada del backend.
- src/database.py: conexión con la base de datos.
- requirements.txt: dependencias de Python.
